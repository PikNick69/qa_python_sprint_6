# Sprint_6
Проект по автоматизации тестирования сервиса «Яндекс.Самокат»

## Описание проекта
Автотесты для учебного сервиса «Яндекс.Самокат». Реализованы с использованием Page Object Model, параметризации тестов и формированием Allure-отчетов.


## Запуск всех тестов
pytest -v --alluredir=allure-results
